# Motzei Shabbat Arvit: opening

Section file: `sections/arvit-opening.tex` (in `shabbat-siddur/`).

## Source

- **Text:** *Siddur Edot HaMizrach*, version "Torat Emet 357", as published by
  Sefaria (Sefaria-Export, October 2026): `Weekday Arvit/Barchu` 4–10.
- **Original source:** Torat Emet freeware (toratemetfreeware.com).
- **License:** **Public Domain** (per Sefaria's version metadata).
- **Psalm 144:** *Tanach with Nikkud*, Sefaria (from tanach.us, the
  Westminster Leningrad Codex), **Public Domain** per Sefaria's version
  metadata. Not in Torat Emet's siddur. Maqaf printed as a space, sof pasuq as a
  colon, joiner characters removed (as in the birkon's Psalm 67).
- **Psalm 67:** copied from `shared/texts/birkat-hamazon.tex`, so both books
  print the same text.

## Editorial decisions

- The source's verses (צְבָאוֹת עִמָּנוּ …), Half Kaddish and וְהוּא רַחוּם before
  Barechu are kept from Torat Emet.
- **Not included:** the Rosh Hodesh psalm and לְשֵׁם יִחוּד.
