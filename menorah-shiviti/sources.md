# Menorah Shiviti: sources, counts, licenses, decisions

## Text of Psalm 67: candidate editions (not yet chosen)

All three come from the public Sefaria export bucket
(`storage.googleapis.com/sefaria-export/json/Tanakh/Writings/Psalms/Hebrew/`).
Counts are produced by `tools/count_psalm67.py`.

| Edition (Sefaria version title) | Underlying source | License |
|---|---|---|
| Tanach with Ta'amei Hamikra | Westminster Leningrad Codex (tanach.us) | Public Domain |
| Tanach with Nikkud | same, cantillation removed | Public Domain |
| Miqra according to the Masorah (MAM) | Hebrew Wikisource, Aleppo Codex tradition | CC-BY-SA |

MAM's CC-BY-SA license would require attribution and, arguably, releasing the
poster under the same license: not suitable for a commercial piece unless
Yosef decides otherwise. The Leningrad editions are public domain.

| Verse | Leningrad (tanach.us) | MAM | Effect on counts |
|---|---|---|---|
| 1 | לַמְנַצֵּחַ without patach genuva | with patach genuva | none |
| 2 | יְחָנֵּנוּ (qamats) | יְחׇנֵּנוּ (qamats qatan sign) | none |
| 2 | יָאֵר and פָּנָיו as separate words | joined by an implicit maqaf | none (49 words either way, maqaf split) |
| 3, 8 | בְּכָל, כָּל (qamats) | בְּכׇל, כׇּל (qamats qatan sign) | none |
| 5 | מִישׁוֹר (with vav) | מִישֹׁר (defective) | v5 letters: **48** vs **47** |
| 8 | אֹתוֹ (defective) | אוֹתוֹ (full) | v8 letters: **29** vs **30** |
| 4, 5, 6 | paseq as a plain character | paseq marked up separately | none |

The Torat Emet siddur text (used elsewhere in this repo) agrees with the
Leningrad counts.

## Draft text in use

`psalm67.lua` (generated by `tools/make_psalm67_lua.py`) holds the Leningrad
text, "Tanach with Ta'amei Hamikra", as a **provisional** choice for the
draft: public domain, and it matches Torat Emet. Until Yosef decides how to
treat the name Elohim in source files, those words are stored as Unicode
code-point escapes, never spelled out. The text is **letters only** in
every format (Yosef): no nikud, te'amim, sof pasuq or paseq, and each maqaf
becomes a word break, so the words per verse are 4, 7, 6, 6, 11, 6, 6, 7
(49 in verses 2-8). Spellings follow Yosef's siddur where it differs from
Leningrad (the `SIDDUR` table in the generator): בנגינות (v1), מישר (v5),
אותו (v8).

## Fonts

- Hebrew: **Stam Sefarad CLM** (Culmus Project, GPL with font exception:
  free for commercial use, embedding allowed). A Sephardic STaM hand with
  tagin. Ships with TeX Live and Overleaf (`StamSefaradCLM.ttf`), so it is
  **not** copied into the repo. Loaded in `main.tex` as `\stamfont`, used for
  all Hebrew in the piece.
- Latin (draft label only): Gentium Plus, from `shared/fonts/`.

## Technical decisions

- Text on curved branches: whole words as TikZ nodes, each rotated to the arc
  tangent, spaced along the arc by measured width (tested with verse 2, nikud
  and te'amim: marks stay attached, order is right to left). The picture is
  drawn in a left-to-right (English) context with each node set in Hebrew;
  inside a Hebrew paragraph the TikZ canvas comes out mirrored.
- `decorations.text` (text along a path) is ruled out: it reverses the letter
  order and detaches the points.

## Decisions by Yosef

- **Formats:** one design, several outputs:
  - ACEO cards (2.5 x 3.5 in);
  - a page for each book size: `siddur` 3.5 x 4.75 in (Shabbat siddur) and
    `birkon` 4.25 x 5.5 in (birkon and Seder HaShulchan);
  - a poster (size not chosen);
  - possibly a stencil, hand printed on fine paper for posters and cards
    (printing method not chosen).
- **Reading order (from a traditional example he shared):** verse 1 across
  the top of the menorah; then verse 2 down the left-most branch, verse 3 down
  the next, and so on, left to right, with verse 5 vertical down the centre
  shaft (not stacked horizontal lines). Every branch reads from its lamp
  downward.
- **No punctuation:** sof pasuq, paseq and maqaf are removed; words joined by
  a maqaf are set as separate words.
- **Letters only:** no nikud or te'amim, in every format.
- **Base:** verse 5 is split; its start runs down the shaft and its last words
  form the base of the menorah, set horizontally: the last **three** words,
  בארץ תנחם סלה (`base_words` in `menorah.lua`). The shaft reaches well
  below the curved branches, so the base sits clearly under them.
- **Lower curves of the left branches:** the text keeps following the path,
  so words there are nearly upside down. That is as it should be (Yosef).
- **Spelling:** follows Yosef's siddur (photo of its shiviti page, Shacharit):
  בנגינות in verse 1 (Leningrad בנגינת), מישר in verse 5 (Leningrad מישור),
  אותו in verse 8 (Leningrad אתו). The siddur's base is four words; Yosef
  chose three for this piece.
- **Above the menorah:** Psalm 16:8, with the Name large (unpointed) in the
  centre, שויתי to its right, לנגדי to its left and תמיד beneath it. The
  Name is assembled from code points in `menorah.lua` (`the_name()`), never
  written out.
- **Base arched**, as in his siddur: the base words run over the top of a
  shallow arch under the shaft. Still three words (his earlier decision;
  the siddur arches four).
- **No guide lines** under the text (Yosef).
- **Font:** Stam Sefarad CLM for all the Hebrew of this piece (Yosef).
