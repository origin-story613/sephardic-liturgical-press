A poster of Modim deRabanan, the congregation's Modim during the chazzan's
repetition of the Amidah. A poster-type art piece in the family of the
shivitis (`menorah-shiviti/`, `menorah-shiviti-2/`), but not a shiviti.
Not started: design still to be decided with Yosef. See `sources.md`.

The rules of `menorah-shiviti/HANDOFF.md` apply: the Name is never written
out in any file (build it from code points, or use `\Shem{}`), pushes go
through a pull request that the session merges itself, Overleaf syncs from
