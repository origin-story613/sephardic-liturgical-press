# Birkat Kohanim poster

Birkat Kohanim (Numbers 6:24-26) set as a spiral running inward, with a
hamsa at the centre. First draft.

- Main document: `birkat-kohanim/main.tex` (LuaLaTeX; compile twice). The
  format is set by `\birkatformat` at the top (aceo, siddur, birkon, poster).
- `text.lua` is generated by `make-text.py` from the Sefaria export;
  `spiral.lua` lays out the spiral and draws the hamsa.
- Decisions and sources: `sources.md`. Background for poster work:
  `new-poster/HANDOFF.md`.
