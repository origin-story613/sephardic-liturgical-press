# Ani LeDodi (Ahava poster)

A poster for Yosef's wife: the whole of Shir HaShirim as a dense background,
with a large 2x2 block of אהבה over it. Draft.

- Main document: `ani-ledodi/main.tex` (LuaLaTeX; compile twice). The format
  is set by `\ahavaformat` at the top (aceo, siddur, birkon, poster).
- `text.tex` is generated by `make-text.py` from the Sefaria export.
- Decisions and sources: `sources.md`. Background: `HANDOFF.md`.
